# Desktop Copy File Checker

A Windows utility developed by **Bytetastic App Productions** to scan your Desktop for files and folders containing `Copy` in their names.

## Download

**[Download the latest version](YOUR-GITHUB-RELEASES-LINK)**

1. Open the latest GitHub Release.
2. Scroll down to the **Assets** section.
3. Download `Desktop Duplicate File Checker.exe`.
4. Open the downloaded application.

> Always download the application from the official GitHub repository.

## Features

- **Desktop Scanning** – Scans the current user's Desktop.
- **Copy Detection** – Finds files and folders containing `Copy` in their names.
- **Item Statistics** – Counts the files and folders on the Desktop.
- **Timestamped Audit Reports** – Generates a report listing matching files and folders.
- **Automatic Deletion** – Offers the option to delete all matching items.
- **Manual Review** – Lets you review matching files and folders individually.
- **Deletion Confirmation** – Displays a warning before automatic deletion.
- **Report Management** – Lets you choose whether to keep or delete the generated report.

## How to Use

1. Launch `Desktop Duplicate File Checker.exe`.
2. Read the welcome message.
3. Select **Yes** to start scanning your Desktop.
4. Wait for the scan to finish.
5. Review the generated audit report.
6. Choose what to do with the matching items.

## Deletion Modes

### Automatic Deletion

Select **Yes** when asked to choose a deletion mode.

- Displays a final warning.
- Requests confirmation before proceeding.
- Deletes all matching files and folders if confirmed.

### Manual Review

Select **No** when asked to choose a deletion mode.

- Reviews matching folders individually.
- Reviews matching files individually.
- Lets you choose whether to delete or keep each item.

### Skip Deletion

Select **Cancel** to skip deletion.

The report records that deletion was skipped.

## Audit Reports

The application generates a timestamped text report on your Desktop.

The report includes:

- Total number of files and folders counted.
- Matching folders containing `Copy` in their names.
- Matching files containing `Copy` in their names.
- Modification dates of matching items.
- Deletion actions performed.
- Items kept during manual review.

## Important Information

**Copy Detection**

The application searches for the word `Copy` in file and folder names. It does not compare file contents or determine whether two files are identical.

**Deletion Warning**

Deleting files and folders can result in permanent data loss. Automatic deletion can remove all matching items, including folders and their contents.

Always review the report carefully before deleting anything.
